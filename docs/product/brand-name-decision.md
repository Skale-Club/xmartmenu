# Brand name: keep XmartMenu or rename?

Status: **open**, owner decision pending (XMM-D-2026-11-12-brand-name).

**Source of truth:** Notion, Projects → XmartMenu → [Brand Name Research](https://app.notion.com/p/416b7a6861218102b297f0d07a74beaa). Add every new candidate, check and verdict there. This file is a short repository copy.

## Naming rules (owner, 2026-11-12)

1. The X is a pun: it stands in for a sound of a real word, such as S / Es / Sch, Sh / Ch, Z or E / Ex (Xpot = spot, Xpeed = speed, Xphere = sphere, Xkedule = schedule, Xcraper = scraper, Xareable = shareable, Xtimator = estimator, Xtudio = estúdio, Xmail = e-mail).
2. One word, like every Skale Club app.
3. Out of the ordinary, not generic.
4. A buyable domain (any extension).
5. Works in English (US market) and fits a restaurant menu product.

## Why XmartMenu is being reconsidered

- Two words; "smart" is generic. No rationale was ever recorded for the 2026-04-10 rename (commit `1dc7b82`).
- Spoken it is "Smart Menu". EveryBite sells SmartMenu to US restaurants and filed SMARTMENU (USPTO serial 99741790, pending); "smart menu" is treated as descriptive (eTouch LV reg. 6050022, Supplemental Register).

Later rules (owner, 2026-11-12): fits every kind of restaurant (fine dining to tavern, vegetarian), sounds like a premium tool, the word "menu" is welcome (for example through the .menu domain), hidden references only if elegant, and a real conflict check before scoring.
