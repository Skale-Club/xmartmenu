## 4. Production catalog (read-only, metadata only)

Collected in a `BEGIN READ ONLY` transaction; no table rows read.

### Confirmed

- **A01 — critical.** `profiles_update_self`: `UPDATE USING (id = auth.uid())`,
  no `WITH CHECK`. `authenticated` (and `anon`) hold column `UPDATE` on
  `profiles.role` and `profiles.tenant_id`. The only trigger on `profiles` is the
  audit trigger. `is_superadmin()` returns `role = 'superadmin'` from `profiles`.
  Any signed-in account can therefore make itself superadmin or join another
  tenant through PostgREST.
- **A14.** `chat_conversations_public_insert` and `chat_messages_public_insert`:
  `INSERT ... WITH CHECK (true)` for role `public`.
- **A19 (new).** `get_menu_analytics_overview`, `get_menu_product_analytics` and
  `get_menu_upsell_analytics` are `SECURITY DEFINER`, executable by `anon` and
  `authenticated`, take `p_tenant_id` and do not check the caller. Revenue,
  funnel and upsell figures of any tenant are readable with the public anon key.
  (`get_menu_engagement`, `get_order_attribution` and `get_platform_menu_overview`
  are correctly limited to `service_role`.)

## 7b. Found while fixing (2026-10-27)

- **Policy drift.** The RLS policies in production do not match a database
  built from the migrations (production: `products_select`,
  `products_insert`…; migrations: `products_public`, `products_tenant_read`,
  `products_admin_*`). Permissive policies add up, so the privilege
  migrations drop every policy of the command they redefine (loop over
  `pg_policies`) instead of dropping by name. Same end state everywhere.
- **Staff could set any order status**, including `paid`, through
  `PATCH /api/orders/[id]`, and the board's `out_for_delivery` was rejected.
- **`getEffectiveTenant()` accepted any role**; 47 routes only deny
  `store-staff`, so customers and unknown roles passed.
- **AI billing could charge twice** after a failed "mark invoiced" step.
- **Rate limits failed open** in production (no Redis) and trusted the
  client-written `x-forwarded-for`.
- **Auth callback open redirect** via `next=@host`.
- **Onboarding** left orphan tenants on partial failure and duplicated on
  concurrent submits.
- **Overlays** did not manage keyboard focus.
- Production latency baseline (read-only, 15 samples): `/` p50 188 ms /
  p95 550 ms; tenant menu p50 442 ms / p95 654 ms (144 KB).
